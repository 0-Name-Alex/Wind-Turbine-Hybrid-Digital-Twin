## 2. Architecture & Pipeline Order
The Streamlit app [`digital_twin_app.py`](digital_twin_app.py) consumes artifacts generated by standalone model scripts:
1. **`power_model.py`** -> outputs to `outputs_power_model/` (learned power-curve model)
2. **`fault_detection.py`** -> outputs to `outputs_fault_detection/` (SCADA feature pipeline, anomaly detection, subsystem scores)
3. **`forecast_model.py`** (optional) -> outputs to `outputs_forecast/` (short-term 3-h power forecast)
4. **`health_trend.py`** -> time-to-alarm trend evaluation (`Reports` page)
5. **`physics_twin.py`** -> analytical aerodynamic $C_p(\lambda, \beta)$ & mechanical torque model compared side-by-side in `Hybrid Twin`
6. **`twin3d.py`** -> offline WebGL 3D turbine renderer driven by rotor speed, pitch, wind, and part health
7. **`synthetic_turbine.py`** -> optional live synthetic turbine simulator with fault injection
8. **`matlab/`** (`build_twin_model.m`, `calibrate_twin.m`, `run_twin.m`, `wt_twin.slx`) & `export_for_matlab.py` -> MATLAB/Simulink co-simulation & SCADA comparison (uses `CARE_To_Compare/` and `matlab/matlab_data/`).
